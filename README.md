# health-log 💪🏃

パーソナルトレーナー（Claude）と一緒に、**筋トレ・ランニング・体調・食事**を記録して管理するリポジトリ。

## 🎯 いまの目標

| 目標 | 内容 | 期限 |
|---|---|---|
| いい身体を作る | 大胸筋と腕をたくましくする | 継続 |
| NAHAマラソン | 完走＋**5時間前後**でゴール（目安ペース 約7:05/km） | 2026年12月（第1日曜の予定。日付は要確認） |

## 📁 ファイル構成

| ファイル | 中身 |
|---|---|
| [`CLAUDE.md`](CLAUDE.md) | トレーナーのキャラ設定と、記録・提案のルール |
| [`history.md`](history.md) | これまでの記録（スプレッドシート）の分析 |
| [`profile.md`](profile.md) | 身長・体重・ベスト記録など（あとで記入） |
| [`program.md`](program.md) | 筋トレの組み方と重量アップのルール（理由つき）、マラソンまでの計画 |
| [`nutrition.md`](nutrition.md) | 食事の目安と、レース前の食べ方 |
| [`logs/2026/`](logs/2026/) | 月ごとの記録（筋トレ・ラン・体調・コメント） |
| [`data/training-log.csv`](data/training-log.csv) | 2021年からの筋トレ記録（スプレッドシート「MASSLE」から書き出したもの。コメントは除いている） |
| [`data/inbody.csv`](data/inbody.csv) | InBodyの体重・体脂肪率 |

## 🔁 使い方

1. その日の調子（睡眠・疲れ・痛み）を伝える
2. トレーナーがその日のメニューを提案する
3. 終わったら結果を伝える → `logs/` に記録して、コメントと次回の調整を書く
4. 月の終わりに振り返り（走った距離の合計・重量の伸び・体重の変化）
